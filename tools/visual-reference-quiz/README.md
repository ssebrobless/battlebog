# Battle Bog Visual Reference Quiz

Open `index.html` in a browser. No build or local server is required.

The quiz stores progress in browser `localStorage` and can export:

- a human-readable Markdown preference brief;
- structured JSON for later research automation.

Each card distinguishes:

- `Love`: Battle Bog should visibly pursue this direction.
- `Useful`: mine a named technique without inheriting the whole appearance.
- `Unsure`: more footage or a prototype is needed.
- `Reject`: retain as an explicit visual boundary.

Local images are reference thumbnails captured from official Steam store
galleries or the linked gameplay-video thumbnail. Every card links back to its
source and states what that source can and cannot establish.

These images are research evidence only. They are not Battle Bog production
assets and are not authorized for reuse in the game.
